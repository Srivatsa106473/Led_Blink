✨ LED Fade with Arduino

This Arduino sketch demonstrates how to smoothly fade an LED in and out using PWM (Pulse Width Modulation) on pin 9.

🔹 How it works

The LED brightness gradually increases from 0 (off) to 255 (full brightness).

Holds for 1 second at max brightness.

Then brightness decreases from 255 back to 0.

Holds for 1 second at minimum brightness.

The cycle repeats indefinitely, creating a smooth fade effect.
